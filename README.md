# Mapa base gris

Teselas raster (256 px, WebP) en dos estilos: `oscuro/{z}/{x}/{y}.webp` (hasta zoom 16) y `claro/{z}/{x}/{y}.webp` (hasta zoom 15). Detalle completo solo en Mar del Plata, Argentina.

Datos: © colaboradores de [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL), a partir de los recortes de [Protomaps](https://protomaps.com) del 24/11/2026. Todo uso de estas imágenes debe citar a OpenStreetMap.
